TypeFast for OS/2
=================

TypeFast is a typing practice game for OS/2 and ArcaOS.

Words fall from the top of the screen. Type each word and press
Space or Enter before it reaches the bottom. The faster you type,
the higher your score.

REQUIREMENTS
------------
- OS/2 Warp 4.52 or ArcaOS 5.x
- TYPEFAST.DAT word file in the same directory as typefast.exe

HOW TO PLAY
-----------
1. Run typefast.exe from the same directory as TYPEFAST.DAT.
2. Type the falling words and press Space or Enter to submit.
3. The game starts as soon as you press the first key.
4. You lose a word for each one that reaches the bottom.
5. After 15 lost words the round ends - select Game > New Game to play again.

MENUS
-----
Game > New Game      Ctrl+N   Start a new game
Game > Pause         Ctrl+P   Pause / resume
Game > Quit Game     Ctrl+Q   End current game
Game > Exit          Ctrl+X   Close the application

Options > Difficulty         Set word drop speed (Easy / Medium / Hard)
Options > Sound      Ctrl+S   Toggle sound effects
Options > Respect Case Ctrl+C Toggle case-sensitive matching
Options > Language           Select interface language
Options > Background Run Ctrl+B  Keep game running when window loses focus
Options > Frame Controls Ctrl+F  Hide / show title bar and menu
Options > Save settings on exit  Save options to TYPEFAST.CFG on exit

Help > About TypeFast         Show version information

WORD FILE
---------
TYPEFAST.DAT is a plain-text file. Replace it with any text file
to practice typing your own vocabulary. The game picks random words
from it (words must be 3+ characters, no punctuation).

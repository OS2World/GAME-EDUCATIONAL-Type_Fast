# TypeFast for OS/2

Typing practice game for OS/2 and ArcaOS. Words fall from the top of the
screen; type each word and press Space or Enter before it reaches the bottom.

## Build

Requires OpenWatcom C/C++ and OS/2 Toolkit 4.5 on ArcaOS or OS/2 Warp.

```
compile-wat.cmd
```

Output: `bin\typefast.exe`
